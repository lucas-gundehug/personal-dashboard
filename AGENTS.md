# personal-dashboard

A personal start page ("new tab" dashboard) with weather, news, an Outlook
calendar, Spotify, shortcuts and a few hidden games, plus a workout plan
(`/workout`), a CV page (`/cv`) and a drink calculator (`/calculate`).
Archived template: see README.md for what it does and how to set it up.

## Stack

TanStack Start (React 19, SSR, file-based routes in `src/routes/`), Vite,
Tailwind CSS 4, shadcn/ui components, Vitest. Package manager: Bun.
Deploys to Vercel through Nitro's `vercel` preset.

## Where things live

- `src/site.config.ts`: owner name, site URL, default weather city.
- `src/data/cv.ts`: CV content (an example person).
- `.env.example`: every environment variable, with what it does.
- `supabase/schema.sql`: tables for the workout plan.
- `src/routes/api/`: server routes; `src/lib/`: server and shared logic.

## Checks

Run before every commit:

```bash
bun run lint && bun run typecheck && bun run test && bun run build
```

`src/routeTree.gen.ts` is generated by the build; commit it when routes change.
The UI text is Danish; code, comments and docs are English.
